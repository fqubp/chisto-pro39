# Чисто-про39 — сайт клининговой компании

PHP-сайт с админпанелью, БД, Telegram-уведомлениями и SMTP-почтой.

---

## Быстрый старт на Timeweb

### 1. Загрузка файлов

Скачай репозиторий и загрузи **все файлы** в папку `public_html` через файловый менеджер Timeweb или FTP.

> ⚠️ Убедись что папки `vendor/`, `css/`, `js/`, `images/`, `admin/`, `includes/` загружены полностью.

---

### 2. Создание базы данных

В панели Timeweb → **MySQL** → Создать базу данных.

Запиши:
- Хост (обычно `localhost`)
- Название БД
- Пользователь БД
- Пароль

---

### 3. Создание таблиц

В Timeweb → **phpMyAdmin** → выбери свою БД → вкладка **SQL** → вставь содержимое файла `database.sql` → **Вперёд**.

Будут созданы таблицы:
- `requests` — заявки с сайта
- `reviews` — отзывы клиентов
- `gallery_items` — галерея До/После

---

### 4. Настройка .env

Создай файл `.env` в корне сайта (рядом с `index.php`) со следующим содержимым:

```env
# База данных
DB_HOST=localhost
DB_NAME=имя_базы
DB_USER=пользователь
DB_PASS=пароль
DB_PORT=3306

# SMTP (mail.ru)
SMTP_HOST=smtp.mail.ru
SMTP_PORT=465
SMTP_USER=chisto-pro39@bk.ru
SMTP_PASS=твой_пароль
SMTP_FROM=chisto-pro39@bk.ru
SMTP_FROM_NAME=Чисто-про39

# Сайт
APP_URL=https://твой-домен.ru

# Админ
ADMIN_EMAIL=chisto-pro39@bk.ru
ADMIN_PASSWORD=твой_пароль_от_админки

# Telegram
TELEGRAM_BOT_TOKEN=токен_бота
TELEGRAM_CHAT_ID=id_чата
```

> ⚠️ Файл `.env` **не загружается в GitHub** автоматически — создай его вручную на хостинге.

---

### 5. Права на папки

Через файловый менеджер Timeweb установи права **755** на папки:
- `uploads/`
- `uploads/gallery/`

Если папок нет — создай их вручную.

---

### 6. Проверка

Открой `https://твой-домен.ru/debug.php` — увидишь:
- Версию PHP
- Статус `.env`
- Статус подключения к БД
- Список таблиц

Если всё зелёное — **удали `debug.php`** с хостинга.

## Админпанель

Адрес: `https://твой-домен.ru/admin/`

Логин: email из `ADMIN_EMAIL` в `.env`  
Пароль: из `ADMIN_PASSWORD` в `.env`

### Возможности:
- **Заявки** — просмотр, смена статуса (новая / в работе / выполнена)
- **Отзывы** — добавление, редактирование, публикация/скрытие, удаление
- **Галерея** — загрузка фото До/После, категории, сортировка, публикация

---

## Уведомления

**Telegram** — работает сразу при правильном `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`.

**Email (SMTP)** — настроен через mail.ru, порт 465 (SSL). Если не приходит — проверь пароль приложения в настройках mail.ru.

---

## Важные заметки

- После загрузки на хостинг **удали `debug.php`**
- Файл `.env` не должен быть доступен публично — проверь что `.htaccess` работает
- Папка `uploads/` должна иметь права на запись (755)
- Таблицы БД создаются один раз через `database.sql`
