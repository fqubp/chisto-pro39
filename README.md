# Чисто-про39 - Сайт клининг-компании

## Быстрая настройка на TimeWeb

### Шаг 1: Регистрация и заказ хостинга
1. Перейди на сайт: https://timeweb.ru/
2. Нажми "Регистрация"
3. Введи email, придумай пароль
4. Подтверди email и войди в личный кабинет
5. Закажи хостинг — любой базовый тариф для PHP сайта
6. Добавь домен в панель или используй временный домен от TimeWeb

### Шаг 2: Настройка базы данных
1. Перейди в панель TimeWeb → раздел "Базы данных" → "MySQL"
2. Создай новую базу данных
3. Создай пользователя базы данных
4. Дай этому пользователю права на новую базу
5. Обычно `DB_HOST=localhost` на TimeWeb

### Шаг 3: Подготовка файлов и загрузка сайта
1. Скачай проект с GitHub или используй локальную копию
2. Подключись по FTP к TimeWeb:
   - Сервер: `ftp.timeweb.ru`
   - Порт: `21`
   - Логин/пароль: из панели TimeWeb
3. Зайди в папку `public_html` вашего сайта
4. Загрузи все файлы и папки проекта в эту папку
5. Убедись, что папка `uploads/` существует и доступна для записи

### Шаг 4: Создание `.env`
1. Скопируй `.env.example` в `.env`
2. Открой `.env` и заполни свои данные
3. Пример для TimeWeb:

```
# База данных
DB_HOST=localhost
DB_NAME=имя_вашей_базы
DB_USER=имя_пользователя
DB_PASS=пароль_пользователя
DB_PORT=3306

# SMTP настройки (Yandex.Connect)
SMTP_HOST=smtp.yandex.ru
SMTP_PORT=465
SMTP_USER=ваша_почта@yandex.ru
SMTP_PASS=пароль_приложения_яндекса
SMTP_FROM=ваша_почта@yandex.ru
SMTP_FROM_NAME=Чисто-про39

# Другие настройки
APP_URL=https://ваш_домен_на_timeweb.ru
ADMIN_EMAIL=ваш_email@пример.ru
```

4. Сохрани файл и загрузите `.env` на сервер

### Шаг 5: Импорт базы данных
1. Открой `phpMyAdmin` в панели TimeWeb
2. Выбери созданную базу данных
3. Перейди во вкладку "SQL"
4. Вставь содержимое `database.sql`
5. Нажми "Выполнить"

### Шаг 6: Проверка сайта
1. Открой сайт по домену: `https://ваш_домен_на_timeweb.ru`
2. Проверь главную страницу
3. Открой `https://ваш_домен_на_timeweb.ru/test.php`
   - там должно быть видно: подключение к БД, папка uploads и наличие PHPMailer

### Шаг 7: Тестовая заявка и админка
1. Заполни форму заявки на сайте
2. Проверь, что файлы загружаются и сохраняются
3. Войди в админку: `https://ваш_домен_на_timeweb.ru/admin/`
4. Логин: `admin`, пароль: `LiTNa3I%`

### Важные файлы для загрузки
- Все PHP-файлы из корня
- `includes/`
- `css/`
- `js/`
- `admin/`
- `private/`
- `business/`
- `database.sql`
- `composer.json`
- `composer.lock`
- `.env` (создаётся вами)

### Полезные советы
- Если сайт находится в папке, а не в корне домена, укажи это в `APP_URL`.
- Если сайт не открывается — сначала проверь `.env` и права MySQL.
- Если почта не работает, попробуй временно отключить SMTP, чтобы сайт не падал.
