## 1. Общее описание

Web-сервис решает две задачи: маркетинговое представление компании и автоматизация операционных процессов — приём заявок, назначение рабочих, уведомления через Telegram, отслеживание статусов.

### Технологический стек

| Компонент | Технология |
|---|---|
| Серверная часть | PHP 8.2 (процедурный стиль) |
| База данных | MySQL 8.0, MySQLi prepared statements |
| Фронтенд | HTML5, CSS3, JavaScript (без фреймворков) |
| Отправка почты | PHPMailer 6.x, SMTP/SSL |
| Уведомления | Telegram Bot API (sendMessage, JSON/cURL) |
| Хостинг | TimeWeb |
| Конфигурация | .env, закрытый через .htaccess |

### Роли пользователей

| Роль | Описание |
|---|---|
| **Клиент** | Оставляет заявку, использует калькулятор, отслеживает статус по номеру телефона. Без регистрации. |
| **Рабочий (клинер)** | Получает Telegram-уведомления о назначении на объект. Нет доступа к сайту. |
| **Менеджер** | Принимает звонки, назначает рабочих, меняет статусы, редактирует стоимость в админпанели. |
| **Веб-администратор** | Полный доступ к админпанели: рабочие, отзывы, галерея, все заявки. |

## 3. Функционал

### 3.1 Калькулятор стоимости

**Формула:** `(тариф_за_м² × площадь) + (кол-во_комнат × 750) + доп_услуги`

| Тип уборки | Тариф |
|---|---|
| Поддерживающая | 150 руб/м² |
| Генеральная | 250 руб/м² |
| После ремонта | 400 руб/м² |

Дополнительные услуги: мойка окон (+1 500 руб), холодильник (+750 руб), духовка (+1 000 руб), химчистка мебели (+2 500 руб).

### 3.2 Обработка заявки (submit_request.php)

1. Проверка CSRF-токена (`hash_equals`)
2. Honeypot-проверка (скрытое поле `website`)
3. Rate limiting — не более 5 заявок/час с одного IP (SHA-256)
4. Валидация данных (`clean_input`)
5. Загрузка файлов — до 5 файлов по 10 МБ, проверка MIME-типа
6. Генерация токена отслеживания (`bin2hex(random_bytes(16))`)
7. INSERT в БД через prepared statement
8. Telegram-уведомление менеджеру
9. Email-уведомление через PHPMailer + SMTP
10. Редирект на `thank_you.php?token=...`

### 3.3 Отслеживание статуса (track.php)

- Поиск по номеру телефона (нормализация → REGEXP_REPLACE)
- Поиск по прямой ссылке с токеном (`?token=xxxxxxxx`)
- Прогресс-бар: **Принята → В работе → Выполнена**

### 3.4 Назначение рабочих (admin/index.php)

Модальное окно с чеклистом активных рабочих. При сохранении:
- Данные пишутся в `requests` (address, area_sqm, rooms, scheduled_at)
- Записи добавляются в `request_workers`
- Только **новым** рабочим отправляется Telegram-уведомление

## 4. Telegram-уведомления

### Менеджеру — при новой заявке:
```
🆕 Новая заявка #N
👤 Клиент: имя
📞 Телефон: номер
🔧 Услуга: тип
💰 Стоимость: ~сумма руб
💬 Комментарий: текст
```

### Рабочему — при назначении на объект:
```
🧹 Вас назначили на объект!
📋 Заявка №N
👤 Клиент: имя
📞 Телефон: номер
📍 Адрес: адрес объекта
🔧 Услуга: тип
📐 Площадь: X м²
🚪 Комнат: N
📅 Дата: дд.мм.гггг ЧЧ:ММ
```

## 5. База данных

СУБД: MySQL 8.0 | Кодировка: utf8mb4_unicode_ci | Движок: InnoDB | Таблиц: 5

### requests (заявки)
| Поле | Тип | Описание |
|---|---|---|
| id | INT PK AUTO | Идентификатор |
| name | VARCHAR(255) | Имя клиента |
| phone | VARCHAR(20) NOT NULL | Телефон |
| service_type | VARCHAR(255) | Тип услуги |
| message | TEXT | Комментарий |
| file_path | TEXT | JSON-массив путей к файлам |
| estimated_price | VARCHAR(50) | Согласованная стоимость |
| source_ip | VARCHAR(64) | SHA-256 хеш IP |
| address | VARCHAR(500) | Адрес объекта |
| area_sqm | DECIMAL(7,1) | Площадь в м² |
| rooms | INT | Количество комнат |
| scheduled_at | DATETIME | Дата и время уборки |
| tracking_token | VARCHAR(64) | Токен для отслеживания |
| status | ENUM | new / in_progress / completed |
| created_at | TIMESTAMP | Дата создания |

### workers (рабочие)
| Поле | Тип | Описание |
|---|---|---|
| id | INT PK AUTO | Идентификатор |
| name | VARCHAR(255) NOT NULL | Имя |
| phone | VARCHAR(20) | Телефон |
| telegram_chat_id | VARCHAR(50) | Chat ID для уведомлений |
| is_active | TINYINT(1) | 1 — активен |

### request_workers (назначения)
Связь многие ко многим. `ON DELETE CASCADE`. `UNIQUE KEY (request_id, worker_id)`.

### reviews (отзывы)
| Поле | Тип | Описание |
|---|---|---|
| id | INT PK AUTO | Идентификатор |
| author_name | VARCHAR(255) | Имя клиента |
| rating | TINYINT | Оценка 1–5 |
| review_text | TEXT | Текст отзыва |
| is_published | TINYINT(1) | 0 — скрыт, 1 — опубликован |

### gallery_items (галерея)
| Поле | Тип | Описание |
|---|---|---|
| id | INT PK AUTO | Идентификатор |
| title | VARCHAR(255) | Название работы |
| category | ENUM | apartment/office/furniture/windows/renovation/other |
| before_image | VARCHAR(500) | Путь к фото «До» |
| after_image | VARCHAR(500) | Путь к фото «После» |
| sort_order | INT | Порядок (меньше — выше) |
| is_published | TINYINT(1) | 1 — опубликовано |

## 6. Безопасность

| Угроза | Защита |
|---|---|
| SQL-инъекции | MySQLi prepared statements |
| XSS | `htmlspecialchars()` на всех выводах |
| CSRF | Токены + `hash_equals()` |
| Боты/спам | Honeypot + rate limiting (5 заявок/час) |
| Брутфорс | Блокировка IP на 15 мин после 5 попыток |
| Загрузка файлов | Проверка MIME-типа + запрет PHP в `/uploads/` |
| Конфигурация | `.env` закрыт через `.htaccess` |
| Персональные данные | 152-ФЗ, согласие на обработку, SHA-256 для IP |

## 7. Установка на хостинге (Timeweb)

### 1. Загрузка файлов
Загрузи все файлы в `public_html` через файловый менеджер или FTP.

### 2. База данных
В phpMyAdmin выполни `database.sql` — создаст все 5 таблиц.
> Если БД уже существует — выполни `migrate.sql`.

### 3. Файл .env
Создай `.env` вручную в корне сайта:

```env
DB_HOST=localhost
DB_NAME=имя_базы
DB_USER=пользователь
DB_PASS=пароль
DB_PORT=3306

SMTP_HOST=smtp.mail.ru
SMTP_PORT=465
SMTP_USER=почта@bk.ru
SMTP_PASS=пароль_приложения
SMTP_FROM=почта@bk.ru
SMTP_FROM_NAME=Чисто-про39

APP_URL=https://твой-домен.ru
ADMIN_EMAIL=почта@bk.ru
ADMIN_PASSWORD=пароль_админки

TELEGRAM_BOT_TOKEN=токен_от_BotFather
TELEGRAM_CHAT_ID=id_чата_менеджера
```

### 4. Права на папки
Установи права **755** на `uploads/` и `uploads/gallery/`.

### 5. Проверка
Открой `твой-домен/debug.php` — убедись что всё зелёное.
**После проверки удали `debug.php`.**
