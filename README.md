# Чисто-про39 - Сайт клининг-компании

## Для чайников: пошаговая настройка на SpaceWeb

### Шаг 1: Регистрация на SpaceWeb
1. Перейди на сайт: https://spaceweb.ru/
2. Нажми "Регистрация" в правом верхнем углу
3. Введи email, придумай пароль
4. Подтверди email (проверь почту)
5. Войди в личный кабинет

### Шаг 2: Создание хостинга
1. В личном кабинете нажми "Заказать хостинг"
2. Выбери тариф (начни с самого дешёвого, например "Start" за 99 руб/мес)
3. Выбери домен:
   - Если у тебя есть домен: введи его
   - Если нет: купи новый (chisto-pro39.ru) за 150-300 руб/год
4. Оплати (картой или другим способом)
5. Жди активации (обычно 5-15 минут)

### Шаг 3: Настройка FTP и базы данных
1. В личном кабинете SpaceWeb → "Управление хостингом"
2. **FTP-доступ:**
   - Перейди в "FTP-аккаунты"
   - Создай нового пользователя (логин: chisto, пароль: придумай)
   - Запомни данные: сервер ftp.spaceweb.ru, порт 21

3. **База данных:**
   - Перейди в "Базы данных" → "MySQL"
   - Создай базу: имя `chisto_pro39_db`, кодировка UTF8MB4
   - Создай пользователя: логин `chisto_user`, пароль придумай (запомни!)
   - Дай права этому пользователю на базу

### Шаг 4: Загрузка файлов сайта
1. Скачай ZIP архив с GitHub: https://github.com/fqubp/chisto-pro39/archive/main.zip
2. Распакуй на компьютере
3. Подключись по FTP (используй FileZilla или WinSCP):
   - Сервер: ftp.spaceweb.ru
   - Логин: chisto
   - Пароль: твой FTP пароль
   - Порт: 21
4. Загрузи ВСЕ файлы в папку `www/` или корень сайта
5. Убедись, что папка `uploads/` создана и пустая

### Шаг 5: Настройка .env файла
1. В FTP найди файл `.env.example`
2. Скачай его на компьютер
3. Переименуй в `.env`
4. Открой в блокноте и заполни:

```
# База данных
DB_HOST=localhost
DB_NAME=chisto_pro39_db
DB_USER=chisto_user
DB_PASS=твой_пароль_от_базы
DB_PORT=3306

# SMTP настройки (Yandex.Connect)
SMTP_HOST=smtp.yandex.ru
SMTP_PORT=465
SMTP_USER=твоя_почта@yandex.ru
SMTP_PASS=пароль_приложения_яндекса
SMTP_FROM=твоя_почта@yandex.ru
SMTP_FROM_NAME=Чисто-про39

# Другие настройки
APP_URL=https://chisto-pro39.ru
ADMIN_EMAIL=pomianem@bk.ru
```

5. Загрузи обратно на сервер, заменив `.env.example`

### Шаг 6: Настройка Yandex.Connect для почты
1. Перейди на https://connect.yandex.ru/
2. Войди под своей почтой @yandex.ru
3. Перейди в "Почта" → "Настройки"
4. Включи "Внешние приложения" → "Пароли приложений"
5. Создай новый пароль для приложения "Чисто-про39"
6. Скопируй этот пароль в `.env` в поле `SMTP_PASS`

### Шаг 7: Создание таблицы в базе
1. В личном кабинете SpaceWeb → "Управление хостингом" → "Базы данных" → "phpMyAdmin"
2. Войди под пользователем базы
3. Выбери базу `chisto_pro39_db`
4. Перейди во вкладку "SQL"
5. Скопируй содержимое файла `database.sql` и вставь
6. Нажми "Вперёд" - таблица создана!

### Шаг 8: Проверка работы
1. Открой сайт: https://chisto-pro39.ru
2. Заполни форму заявки (с файлами)
3. Проверь админку: https://chisto-pro39.ru/admin/
   - Логин: admin
   - Пароль: LiTNa3I%
4. Проверь почту - должно прийти уведомление

### Шаг 9: Тестирование
1. Открой https://chisto-pro39.ru/test.php
2. Проверь, что всё зелёное (БД подключена, папки есть)
3. Если ошибки - пришли скриншот

### Шаг 10: Финальная проверка
1. Создай тестовую заявку с файлами
2. Войди в админку: https://chisto-pro39.ru/admin/
3. Проверь, что файлы отображаются и скачиваются
4. Убедись, что пришло письмо на pomianem@bk.ru

### Важные файлы для загрузки
- Все PHP файлы из корня
- Папка `includes/`
- Папка `css/`
- Папка `js/`
- Папка `admin/`
- Папка `private/`
- Папка `business/`
- `composer.json` и `composer.lock`
- `database.sql`
- `.env` (создай сам!)
- НЕ загружай: `.env.example`, `.gitignore`, `README.md`, `test.php` (опционально)
