## Деплой на хостинг TimeWeb — пошаговая инструкция

### Шаг 1. Заказ хостинга

1. Зайдите на [timeweb.ru](https://timeweb.ru) → Регистрация.
2. Закажите тарифный план **«Хостинг»** (PHP + MySQL) — базового тарифа достаточно.
3. В личном кабинете привяжите ваш домен или используйте временный `.timeweb.ru`.
4. Выпустите **бесплатный SSL** (Let's Encrypt): Сайты → ваш домен → SSL-сертификат.

---

### Шаг 2. База данных MySQL

1. В панели TimeWeb → **Базы данных → MySQL** → создайте новую БД.
2. Создайте пользователя и дайте ему все права на эту БД.
3. Запишите:
   - Имя базы (например `u123456_chisto`)
   - Пользователь БД (например `u123456_admin`)
   - Пароль
   - Хост: `localhost`

---

### Шаг 3. Импорт структуры базы

1. Откройте **phpMyAdmin** (кнопка в панели TimeWeb рядом с БД).
2. Выберите созданную базу данных слева.
3. Нажмите вкладку **SQL**.
4. Вставьте содержимое файла `database.sql` и нажмите **Выполнить**.

---

### Шаг 4. Создание файла `.env`

Через **Файловый менеджер** TimeWeb (или FTP) в корне сайта создайте файл `.env`.  
Скопируйте из `.env.example` и заполните своими данными:

```env
# База данных
DB_HOST=localhost
DB_NAME=u123456_chisto
DB_USER=u123456_admin
DB_PASS=пароль_от_бд
DB_PORT=3306

# SMTP для BK.ru (Mail.ru)
# !! ВАЖНО: нужен пароль ПРИЛОЖЕНИЯ, не основной пароль от почты !!
SMTP_HOST=smtp.mail.ru
SMTP_PORT=465
SMTP_USER=chisto-pro39@bk.ru
SMTP_PASS=пароль_приложения_bk_ru
SMTP_FROM=chisto-pro39@bk.ru
SMTP_FROM_NAME=Чисто-про39

# URL сайта — без слэша в конце!
APP_URL=https://ваш-домен.ru

# Куда приходят уведомления о новых заявках
ADMIN_EMAIL=chisto-pro39@bk.ru

# Пароль для входа в /admin/ — придумайте надёжный!
ADMIN_PASSWORD=придумайте_надёжный_пароль_минимум_12_символов
```

### Шаг 5. Загрузка файлов на сервер

**Через Файловый менеджер TimeWeb:**
1. Зайдите в Файловый менеджер → перейдите в `public_html/`.
2. Создайте папку `uploads/` (если нет) и установите права **755**.
3. Загрузите архив проекта и распакуйте, или загружайте папки по одной.

**Через FTP (FileZilla или аналог):**
```
Хост:    ftp.timeweb.ru  (или IP сервера из панели)
Порт:    21
Логин:   логин_хостинга
Пароль:  пароль_хостинга
Папка:   /public_html/
```

**Структура в public_html/ должна быть:**
```
public_html/
├── index.php
├── .htaccess
├── .env              ← создаёте вручную!
├── css/
├── js/
├── images/
├── includes/
├── admin/
├── private/
├── business/
├── uploads/          ← права 755
├── vendor/           ← см. Шаг 6
└── ...
```

### Шаг 6. Установка PHPMailer (зависимости Composer)

**Вариант А — через SSH (рекомендуется):**
1. TimeWeb → **SSH-доступ** → подключитесь:
   ```
   ssh логин@ip-сервера
   ```
2. Перейдите в папку сайта:
   ```bash
   cd ~/public_html
   ```
3. Запустите установку:
   ```bash
   composer install --no-dev --optimize-autoloader
   ```

**Вариант Б — вручную (если нет SSH):**
1. Установите зависимости локально командой `composer install`.
2. Загрузите получившуюся папку `vendor/` на сервер в `public_html/vendor/`.

### Шаг 7. Настройка почты BK.ru — получение пароля приложения

> Обычный пароль от почты для SMTP не работает — нужен «пароль приложения».

1. Зайдите на [mail.ru](https://mail.ru) под `chisto-pro39@bk.ru`.
2. Перейдите: **Настройки → Безопасность → Пароли для внешних приложений**.
3. Нажмите **«Создать новый пароль»** → введите название «Сайт».
4. Скопируйте выданный пароль (показывается один раз!).
5. Вставьте в `.env` в поле `SMTP_PASS=`.

### Решение частых проблем

**Белая страница / ошибка 500:**
- Нет файла `.env` → создайте по инструкции Шаг 4.
- Нет папки `vendor/` → установите Composer (Шаг 6).
- Смотрите лог ошибок: TimeWeb → **Логи PHP** → `error_log`.

**Письма не приходят:**
- `SMTP_PASS` — должен быть пароль приложения, не основной.
- Проверьте папку **Спам** в почтовом ящике.
- Убедитесь, что `SMTP_HOST=smtp.mail.ru` и `SMTP_PORT=465`.

**Изображения не отображаются:**
- Проверьте, что папка `images/` загружена на сервер.
- Права на папку: `755`.

**Форма заявки не работает:**
- Проверьте, что база данных создана и таблицы импортированы (Шаг 3).
- Убедитесь, что папка `uploads/` существует и имеет права `755`.

**Калькулятор не считает:**
- Убедитесь, что `js/script.js` загружен на сервер.
- Откройте консоль браузера (F12 → Console) — проверьте ошибки.
